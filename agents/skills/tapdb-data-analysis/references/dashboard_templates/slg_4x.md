# SLG / 4X / 战争策略看板模板

## 核心模块

- 核心 KPI：DAU、联盟活跃、留存、收入、付费率、ARPPU、LTV、服务器生态。
- 新手：建号-新手保护-主城等级-加入联盟-首次出征-首次付费漏斗。
- 成长：主城等级、建筑、科技、兵种、战力分布和升级耗时。
- 联盟/社交：联盟加入率、联盟活跃、捐献、帮助、集结、联盟战参与。
- 战争：侦查、出征、战斗、损兵、治疗、掠夺、迁城、PVP 频次。
- 经济：资源产销、加速道具、兵力、治疗资源、通胀/囤积。
- 赛季/服务器：开服天数、服务器分层、赛季阶段、跨服战、流失与合服风险。
- 付费：加速、资源、礼包、月卡、战令、VIP、鲸鱼/联盟头部贡献。
