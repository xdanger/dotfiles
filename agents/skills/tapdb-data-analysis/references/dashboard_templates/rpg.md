# RPG / ARPG / MMORPG 看板模板

## 核心模块

- 核心 KPI：DAU/PCU、留存、收入、付费率、ARPU/ARPPU、等级分布、战力分布。
- 新手与成长：创角-进入游戏-完成新手-解锁核心系统-首战-首付漏斗。
- 等级/战力：等级留存、升级耗时、战力区间、装备/技能/伙伴培养参与。
- 副本与战斗：副本进入/通关/失败、扫荡、体力消耗、PVE/PVP 参与。
- 社交：公会加入、组队、好友、聊天、交易/拍卖（如有）。
- 经济：金币、钻石、装备材料、强化材料 Faucet/Sink，通胀监控。
- 付费：首充、月卡、成长基金、礼包、抽卡、战令、大 R/鲸鱼贡献。
- 版本/活动：新版本、活动、副本、角色上线前后对比。
