# 休闲 / 超休闲 / 轻度益智游戏看板模板

休闲游戏极度依赖买量与广告变现，应突出获客效率、留存、IAA、关卡漏斗和技术体验。

## 获客与增长数据

- CAC / CPI：不同渠道、媒体、素材的新用户成本。
- CTR & CVR：广告素材点击率、商店页/落地页转化率。
- ROAS：重点看 D1/D3/D7，必要时扩展 D14/D30，用于快速调买量。

## 用户活跃与留存

- D1 / D7 留存：D1 看核心玩法第一印象，D7 看内容消耗度与长线吸引力。
- DAU / MAU 与 DAU/MAU 粘性。
- Session Length & Frequency：每日打开次数、单次时长；休闲游戏通常高频短时。

## 商业化变现

- IAA：Impressions per DAU、广告渗透率、eCPM、广告位收益（激励视频/插屏/Banner）。
- IAP：付费渗透率、首付人数、ARPPU、ARPU。
- LTV：重点预估 D30/D60 LTV，并与 CAC 对比。

## 核心玩法与游戏内行为

- 关卡漏斗：每关进入/通过/失败/重试/退出，定位流失关卡。
- 流失节点：退出前最后行为，尤其关注插屏广告后退出。
- 资源经济：金币/道具 Faucet & Sink，检查溢出或短缺。
- 外围功能参与：签到、转盘、日常任务、奖励领取、激励视频入口。

## 性能与异常监控

- Crash Rate、卡顿率、低端机适配。
- Loading Time：首启、关卡加载，休闲用户对加载等待极敏感。
