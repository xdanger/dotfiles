# 通用运营健康看板模板

适用：无法可靠判断游戏类型，或用户只要求「核心运营看板」。

## 核心模块

- 首屏 KPI：DAU、新增、收入、付费率、ARPU、ARPPU、广告收入、D1/D7 留存、崩溃率（如有）。
- 增长：新增用户/设备、渠道/媒体/国家分布、CPI/CAC、CTR/CVR、ROAS D1/D3/D7/D30。
- 活跃留存：DAU/WAU/MAU、DAU/MAU、启动次数、人均时长、D1/D3/D7/D14/D30 留存、版本留存。
- 变现：IAP 收入、广告收入、付费人数、首付人数、付费率、ARPU/ARPPU、LTV、付费档位分布。
- 玩法行为：新手漏斗、核心玩法入口/完成/失败、任务/活动参与、关键资源产销。
- 技术异常：崩溃率、卡顿率、加载耗时、错误事件、版本/机型异常。

## 不确定类型时的回复

先说明「我会先用通用运营健康看板兜底」，同时列出推断的可能类型和原因，请用户确认后可切换到专用模板。
