# MOBA / FPS / TPS / Battle Royale / 动作竞技看板模板

## 核心模块

- 核心 KPI：DAU/PCU、匹配人数、对局数、人均局数、留存、收入、付费率。
- 匹配与对局：匹配成功率、匹配耗时、开局成功、掉线、对局时长、结算完成。
- 玩法平衡：英雄/武器/角色选择率、胜率、KDA、段位分布、地图/模式热度。
- 排位：段位晋升/降级、赛季活跃、排位参与率、连胜/连败流失。
- 反作弊/公平：举报、封禁、异常胜率、外挂相关事件。
- 变现：皮肤、通行证、宝箱、角色/武器解锁、订阅、限时礼包。
- 技术：延迟、卡顿、崩溃、掉线率、重连率，按地区/机型/网络拆分。
